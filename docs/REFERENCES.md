## How these sources inform the project

Next.js route-handler documentation informed the separation of browser interaction from server-only generation and reporting. PostgreSQL constraints support valid persisted telemetry and generation outcomes. Playwright documentation informed browser isolation and end-to-end assertions. The JMeter manuals informed non-GUI execution, staged threads and HTML reports. Google's scoring guidance and WCAG informed the distinction between an automated audit score and wider accessibility evaluation.
